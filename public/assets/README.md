# 素材目录

## brand/

放置经过授权的 Logo 或品牌图片。默认查找 `fullgoal-logo.png`；未提供时页面使用文字 `FULLGOAL`，不会生成或临摹商标。

## demo/

可放置以下已脱敏、确认可用于内部分享的素材：

- `renderer-before.png`：组件化代表页
- `image-native-after.png`：Image-native代表页
- `ici-outline.png`：13页大纲截图
- `qa-screenshot.png`：QA截图
- `skill-run.png`：Skill运行截图

当前页面使用CSS抽象示意，不伪造内部截图，也不依赖随机网络图片。替换前请确认素材不含人员、客户、账号、绝对路径、内部批注或其他敏感信息。

## icons/

存放后续经过授权的本地图标。当前项目使用 Lucide React 图标，不需要远程资源。
