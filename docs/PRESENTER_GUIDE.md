# 演讲者指南

## 时间安排

- 封面与目录：2分钟
- Part 01 AI基础：约7分15秒
- Part 02 协作方法：约4分30秒
- Part 03 Skill案例：约11分35秒
- 结尾：约50秒

总计约25分钟，保留2–3分钟现场停顿与互动空间。

## 演讲前检查

1. 执行 `npm run build`，确认构建通过。
2. 断开网络测试一次，确认没有远程图片或字体依赖。
3. 浏览16页总览，检查是否仍有待替换素材。
4. 打开讲者备注，快速核对每页衔接句。
5. 在会议室电脑测试 `F` 全屏与投屏比例。
6. 关闭系统通知、聊天弹窗与敏感窗口。

## 快捷键

方向键、PageUp / PageDown、Space用于翻页；Home / End跳到首尾；`O`总览；`N`备注；`F`全屏；`Esc`关闭浮层。

## Speaker Notes

备注只显示在右侧浮层，不默认进入投屏画面。按 `N` 打开；讲解时可先在总览中选页，再打开当前页备注。

## 断网演示

项目全部资源本地运行，不调用API，不依赖远程字体、视频或图片。建议提前执行一次 `npm install` 并保留已构建的 `dist/` 作为备用。

## 备用方案

若浏览器全屏受限，使用浏览器自身的全屏快捷键；若开发服务不可用，运行 `npm run preview` 打开生产构建。最终备用可将 `docs/screenshots/` 中的关键页面截图插入临时文档。
